# Second Brain Starter repository route

For a request to set up, initialize, or get started with a copied workspace, read [ONBOARDING.md](ONBOARDING.md) and follow it exactly. Do not use that route for repository maintenance, source changes, tests, or release work; read [CONTRIBUTING.md](CONTRIBUTING.md) and [SECURITY.md](SECURITY.md) first instead.

This route is a reference instruction for Claude Code-compatible local tools. It does not grant filesystem, shell, network, or administrator access, and it cannot suppress client permission prompts.
