# Privacy and boundaries

Keep secrets outside this starter: `.env` files, API keys, passwords, private client data, unrelated project folders, and personal notes you would not want an assistant to read.

Markdown does not sandbox an assistant. File access depends on the host application, its permissions, and the path you give it. Read only the selected project records named in [00-Meta/AGENTS.md](00-Meta/AGENTS.md), and broaden scope only with an explicit instruction.

This package does not collect data, run a service, configure a tool, or promise automatic enforcement. Treat its privacy rules as a checklist you enforce through folder boundaries and host permissions.
