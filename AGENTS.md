# Second Brain Starter repository route

Use the onboarding route only when the user asks to set up, initialize, get started with a copied Second Brain workspace, or connect a repository to it. For that intent, read [ONBOARDING.md](ONBOARDING.md) and follow it exactly.

For repository maintenance, source changes, tests, or release work, do not start onboarding. Read [CONTRIBUTING.md](CONTRIBUTING.md), [SECURITY.md](SECURITY.md), and the relevant source before changing anything.

To explain how to use or update an installed workspace, whether an install is current, or whether a fix landed, read [template/shared-skills/second-brain-guide/SKILL.md](template/shared-skills/second-brain-guide/SKILL.md) and follow it. It is read-only until the person approves an update.

The onboarding route is a reference instruction for compatible local tools. It does not grant filesystem, shell, network, or administrator access, and it cannot suppress client permission prompts.
