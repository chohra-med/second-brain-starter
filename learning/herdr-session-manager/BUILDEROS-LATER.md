# Left out on purpose

This kit is the smallest thing that works: one master, one tab per task, one board, one decision log. These are deliberately NOT in it. They belong to the paid version, Builder AI OS.

| Left out | Why it waits |
|---|---|
| Comment threads on the board page, and a Send button that writes your answer back to the task | needs a hosted page and an account; this board is one local file |
| Answer-board cards (pick one of several options, change a pick, copy your choices) | a second product on top of the board |
| An experiments loop (A/B arms on a decision point, a lookup before every run) | only worth it once employees run daily |
| A publishing calendar and a daily prepare, review, schedule, send loop | specific to content work |
| Browser publisher roles that fill a Substack or Medium draft | needs a signed-in browser and strict stop rules |
| An org chart of employees that report to each other | two flat employees are enough to learn the idea |
| Per-employee model routing and cost tiers | here the model is one setting, `DISPATCH_MODEL` |
| Rollover automation at a context size | the master command states the rule; nothing enforces it |
| A ledger-driven board that reads live tabs, reports and last lines by itself | here the master writes the words on purpose |
| Restarting a session that was closed without its end routine | rare; resume it by hand with `claude --resume` |
