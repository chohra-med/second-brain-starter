# PARA and CODE

Tiago Forte created both PARA and CODE. They solve different parts of the same problem.

## PARA: where a record belongs

- Projects: active work with a finish line.
- Areas: ongoing responsibilities.
- Resources: reference material and procedures.
- Archives: inactive material kept for retrieval.

This starter also keeps `00-Meta` for operating rules and `05-Daily` for short-lived daily state. Those folders are additions, not replacements for PARA.

## CODE: how work moves

- Capture: record an input before it disappears.
- Organise: put it with the project, area, resource, or archive that owns it.
- Distil: keep the next useful fact, decision, or procedure easy to find.
- Express: use the material to finish and verify an outcome.

PARA gives the file a home. CODE gives the work a direction. A captured task becomes useful when its roadmap row names an owner, evidence, and next action.

## An ordinary knowledge task

Fictional book-swap example: **Capture** Saturday 14:00–16:00, room capacity 12, up to three books each, no cash or sales. **Organise** these inputs in the selected project's facts. **Distil** them into a short agenda and attendee checklist. **Express** a one-page book-swap plan, checking the agenda and checklist against those four facts. The output belongs with the active project; reusable references belong in Resources.
