# Capture

Capture an incoming task in the selected project's `roadmap.md`. Give it an owner, `Open` status, the evidence required for done, and one next action.

Fictional example:

| Item | Status | Owner | Evidence for done | Next action |
| --- | --- | --- | --- | --- |
| Test signup copy | Open | Sam | Three reader notes saved in progress | Send draft to readers |

If the input is only an idea, record it as an idea. Do not manufacture a project or a deadline.

## Inputs

- Working (this run): the incoming task or idea, in the words it arrived in.
- Reference (every run): the selected project's [roadmap](../../01-Projects/Selected-Project/roadmap.md), for its columns and status vocabulary.

## Outputs

- One new row in `01-Projects/Selected-Project/roadmap.md`.

## Human check

Read the new row. Confirm that the owner is a real person and that the evidence for done is something you can collect.
