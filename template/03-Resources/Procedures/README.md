# Procedures map

Read this map to choose the method needed for the current task. Read only the selected procedure and its declared inputs. Paths in the procedures name the seeded `Selected-Project` folder; for a project copied from the template, use the same file names in its own folder.

- [Context](context.md): load selected-project context.
- [Capture](capture.md): record incoming work.
- [Close](close.md): preserve work and evidence.
- [Review](review.md): reconcile open work and choose the next action.
- [Learning and scaling](learning-and-scaling.md): evaluate improvements.

- [First use](first-use.md): personalize missing context, finish a checked result and continue in a new chat.

- Three ways to start, from fastest to fullest, listed in order on Home:
  - [Quick start](quick-start.md): index one to three repositories you name, with approval.
  - [Init](init.md): five questions, saved one at a time. You can stop at any answer.
  - [Complete init](complete-init.md): the full set of questions, in sections you can stop and resume.

- [Extend your workspace](extend.md): add and check a user-owned reference or method.

- [Write a README for one project](showcase-readme.md): an example of three skills used in order, to copy and change.
