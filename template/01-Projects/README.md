# Projects map

Read this map when locating a project.

- [Seeded example project](Selected-Project/README.md): the example `Selected-Project` ships with.
- Connected projects: each lives in `<name>/README.md` here, created by `connect`. A connected repository is staged until its harness receipt exists.
- [Project template](../03-Resources/_templates/project/README.md): a new project is a copy of that folder, placed here under its own name.

Read the project’s own rules before using its records to diagnose or change work.
