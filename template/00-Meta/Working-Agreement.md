# Working agreement

This file is yours. The installer creates it once and never overwrites it. It holds the practices you want every assistant to follow in every project, so you write them once instead of repeating them in each chat.

Read it after `Profile.md` and `Decisions.md`. It owns shared practices. A project's own `Decisions.md` owns that project's exceptions and current work.

Delete the comment markers around an example to turn it on, or write your own lines. An example stays inactive while it is inside a comment.
