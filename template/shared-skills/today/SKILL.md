# Today

Use this when the person types `/today`, starts a work day, or asks what to do now.

Do not use this when:

- The person wants workspace or project context loaded before a task. Use `context`.
- The person wants the day closed and its records written. Use `end-session`.
- The person wants a new task or note captured. Use `second-brain-capture`.

Read and follow `03-Resources/Procedures/today.md`. That procedure owns the reads, the stale-plan rule, the briefing shape and the human check. This skill only names when to use it.
