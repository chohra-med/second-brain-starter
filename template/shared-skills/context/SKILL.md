# Context

Use this when the person types `/context`, with or without a mode after it, for example `/context full` or `/context <project>`.

Do not use this when:

- The person wants the compact note for the selected project before work. Use `second-brain-context`.
- The person wants today's briefing. Use `today`.
- The person wants the session closed. Use `end-session`.

Read and follow `03-Resources/Procedures/context-modes.md`. That procedure owns the three modes, their reads, their stop rules and the report shape. This skill is the `/context` name for it; `context-modes` stays installed under its older name and reads the same procedure.
