# Context modes

Use this when the person asks for workspace context and names a mode, or asks for context without naming one. The person can also invoke it as `/context-modes`, with the mode after it, for example `/context-modes full`.

Do not use this when:

- The person wants the compact note for the selected project before work. Use `second-brain-context`.
- The person wants the session closed. Use `end-session`.
- The person wants one roadmap item matched to its evidence. Use `second-brain-close`.

Read and follow `03-Resources/Procedures/context-modes.md`. That procedure owns the three modes, their reads, their stop rules and the report shape. This skill only names when to use it.
