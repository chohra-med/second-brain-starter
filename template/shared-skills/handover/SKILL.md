# Handover

Use this when a chat has become too long or too cluttered to trust. The person can also invoke it as `/handover`.

Do not use this when:

- The session is finished and its records need writing. Use `end-session`.
- The person wants workspace context loaded into a chat. Use `context-modes`.
- The chat was only a question, with no work to carry over.

Read and follow `03-Resources/Procedures/handover.md`. That procedure owns the signs, the steps, the note shape and the restart prompt. This skill only names when to use it.
