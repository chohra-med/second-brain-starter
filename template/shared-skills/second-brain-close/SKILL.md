# Second Brain close

Use this after completing work for a selected project in an installed Second Brain workspace.

The canonical procedure is `03-Resources/Procedures/close.md`. It is owned by the installed template, not by this skill.

1. Open the roadmap item and its progress entries together.
2. Record what was `Done` in `progress.md` and add the exact evidence under `Verified`.
3. Change the roadmap item to `Verified` only after checking the evidence it requires.
4. Keep unverified work `Open` or `In progress`, then write the remaining work and one `Next` action.
