# Second Brain capture

Use this to record incoming work for a selected project in an installed Second Brain workspace.

The canonical procedure is `03-Resources/Procedures/capture.md`. It is owned by the installed template, not by this skill.

1. Work only in the named selected project's `roadmap.md`.
2. Record a task with its owner, `Open` status, evidence required for done, and one next action.
3. If the input is only an idea, record it as an idea. Do not invent a project, deadline, fact, or verification result.
4. Keep the record concrete enough that a later close or review can check it against evidence.
