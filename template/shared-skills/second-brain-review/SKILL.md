# Second Brain review

Use this before a handoff or during a weekly review for a selected project in an installed Second Brain workspace.

The canonical procedure is `03-Resources/Procedures/review.md`. It is owned by the installed template, not by this skill.

1. Read the selected project's facts, roadmap, decisions, and newest three progress entries.
2. Compare every `Done` claim with its roadmap item and required evidence.
3. Record and repair a conflict when progress says complete while the roadmap remains `Open`; do not report ready while evidence is missing.
4. Put confirmed rules in the appropriate project or global decisions record, then end with one `Next` action.
5. Use the installed learning procedure only when a correction is worth keeping.
