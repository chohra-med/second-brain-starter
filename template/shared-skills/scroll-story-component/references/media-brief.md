# Preparing media for a new story

The runtime scrubs a seekable MP4 story film. A separate optional idle film supplies the opening loop. Both should share aspect ratio, subject, framing and a compatible opening pose.

## Brief before generation

Write a small storyboard with one row per concept: visitor lesson, camera destination, highlighted relationship, hold time, transition and HTML label. Establish the whole subject in the opening. For later concepts, travel within the same scene and allow a stable hold where the label can point to a measured node.

Use this prompt as a starting point with your approved reference frames:

> Use the attached frames as stages of one continuous scene. Preserve the same subject, palette, nodes and connections. Start with the complete subject in a fixed-camera view. Add restrained motion at its outer edges. Travel slowly toward the first relevant region, hold it clearly, then continue to the next region without cutting, replacing, duplicating or nesting the subject. Keep space for the website's short paragraph and HTML labels. End in the supplied final pose. No generated text, captions, logo, audio or independent camera shake. Match each new clip's first pose to the previous clip's final pose.

A prompt only asks for continuity; the frames prove it. Inspect the opening, intermediate camera positions, endpoints and both sides of each join. Reject duplicate outlines, missing structures and camera resets. If exact node identity matters, use one persistent SVG/canvas/3D scene rather than promising an AI film will preserve topology.

## Timeline and output

Record the accepted source files, trims, decoded duration, frame rate, stage starts/navigation seek points and stable label holds. Render or request a muted, browser-compatible H.264 MP4 with fast-start metadata and frequent keyframes. Keep a matching still for every named hold and fallback state. An optional GIF is for sharing a preview; the website uses the MP4 for reversible seeking.

Keep all writing in HTML so it stays sharp and accessible. A measured leader is valid only for the crop and film interval where it was qualified. During camera travel, show a compact semantic label. Review the rendered site at desktop and narrow-phone sizes before sharing it.

External uploads, video generation and paid credits require the task's authorization. Source inspection and local integration do not authorize spending.
