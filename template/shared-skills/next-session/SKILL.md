# Next session

Use this when the person types `/next-session`, optionally followed by a few words saying what the fresh chat is for.

Do not use this when:

- The session is finished and its records need writing. Use `end-session`.
- The person wants to know whether anything is lost before closing the chat. Use `verify-end-session`.
- The chat was only a question, with no work to carry over.

Read and follow `03-Resources/Procedures/handover.md`. That procedure owns the signs, the steps, the note shape and the restart prompt. If the person typed words after the command, put them in the note as the Goal of the fresh chat. This skill is the `/next-session` name for it; `handover` stays installed under its older name and reads the same procedure.
