# Second Brain context

Use this before work on a selected project in an installed Second Brain workspace.

The canonical procedure is `03-Resources/Procedures/context.md`. It is owned by the installed template, not by this skill.

1. Name the selected project folder. Do not scan parent folders, unrelated projects, secrets, or private notes.
2. Follow the installed `00-Meta/AGENTS.md` route in its stated order.
3. Return the procedure's compact note: goal, constraints, open work, latest evidence, next action, and any conflict.
4. If progress and roadmap disagree, name the conflict. Do not call work ready without its required evidence.
