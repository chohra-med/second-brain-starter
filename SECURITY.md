# Security review

The public package is intended to contain only the files in `FILE-ALLOWLIST.txt`. The package scan in `lib/package-scan.mjs`, which runs as part of `node --test`, enumerates every regular package member, compares it to that allowlist, and reports relative paths plus rule identifiers. It never prints matched file content or credential values.

The scanner rejects unallowlisted files, symlink and non-regular members, private-path markers, authorization material, token-shaped JWTs, private keys, credential assignments, personal absolute paths, and encoded versions of those markers. Encoded coverage includes HTML numeric entities, JSON Unicode escapes, UTF-16LE/BE, percent encoding, Base64/Base64URL, and whitespace-wrapped Base64. It scans every shipped regular-file byte, including tests and fixtures, and scans declared before/after diff bytes when they are supplied by the build or review tooling. One harmless test assertion is removed only by its exact path and exact synthetic text before matching; it is not a general test-directory exception. The extracted consumer candidate is scanned as its own tree.

Run the scan from a trusted local checkout with `node --test`. The suite scans the real source root against `FILE-ALLOWLIST.txt` in `test/vendor.test.mjs`, and `test/security.test.mjs` checks most rules on planted fixtures; the private-key and non-regular-member rules have no planted fixture yet. A candidate archive is scanned by the build or review tooling that calls `scanPackage`; this package has no command for it. The scan is a source and archive hygiene check, not a claim that a filename or scanner can secure an AI client, erase data from a copied workspace, or prove an external service's behavior.

If the scan reports a finding, stop distribution, remove the material from the candidate source, run `node --test` again, and re-run the candidate scan in your build or review tooling. Do not paste a flagged value into an issue, commit message, pull request, or support channel. Rotate a real credential through its owner before treating a cleaned copy as safe.
