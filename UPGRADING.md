# Upgrading the free starter

## Before updating

1. Read [CHANGELOG.md](CHANGELOG.md) and confirm the version in [VERSION](VERSION).
2. Duplicate your personalized workspace and label the copy with the date.
3. Get a fresh copy of the update through Git or a ZIP release when one is available.

## Apply an update

1. Keep the fresh update separate from your personalized workspace.
2. Compare the two folders. Preserve your facts, roadmap, progress, project decisions, daily notes, and any records you added.
3. Copy only the procedure or template changes you want into your personalized workspace.
4. If a template changed shape, move your information into the new template manually. Do not replace your personalized files wholesale.
5. Open [Home.md](Home.md) and run one first-loop item to confirm the copied links and workflow still work.

## Recover from an interrupted update

Stop editing the affected workspace. Return to the dated copy made before the update, then repeat the update one file at a time. Plain Markdown remains readable in any text editor, even if Obsidian is unavailable.

There are no automatic migrations or automatic overwrites in this starter.
